Getting Started

VPN-Configs-Russia is an infrastructure for collecting, filtering, and publishing quality VPN configurations.

Quick Start

  1. Visit the Configs page
  2. Choose your config type (Black List, Mobile, White List SNI, or White List CIDR)
  3. Copy the subscription link or scan the QR code
  4. Open your VPN client and import the config
  5. Select a server and connect

Configuration Types

Choose the right config for your network conditions:

🏴 Black List (Standard)

Use for regular internet without heavy blocking. Contains ~1000 configs, updated every 2 hours.

📱 Mobile Optimized

Lightweight configs for mobile devices. ~200 configs with low bandwidth requirements.

🏳️ White List SNI

For SNI-based blocking (mobileoperators using white lists). ~500 configs.

🛡️ White List CIDR

For CIDR-based blocking. Alternative when SNI filtering is active. ~300 configs.

Architecture

VPN-Configs-Russia uses a fully automated pipeline:

Sources → Collection → Normalization → Testing → Filtering → Publishing → CDN

FAQ

Q: Is it safe to use these configs?

A: Configs are collected from public sources. Use at your own risk. Not recommended for banking apps or sensitive accounts.

Q: How often are configs updated?

A: Every 2 hours automatically through GitHub Actions.

Q: Can I contribute configs?

A: Yes! Open a GitHub issue or discussion to add new sources.

Q: Which config should I use?

A: Start with Black List. If it doesn't work, try White List SNI. If that fails, use White List CIDR.

Q: Is the project open source?

A: Yes! Full MIT licensed source code on GitHub.
