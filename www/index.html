⚙️ Core Features

What We Do

Automated infrastructure for managing VPN configurations with real-time quality assurance.

🔄

Automatic Collection

Collects from verified sources in real-time. Supports base64, plain-text, and JSON formats.

✅

Smart Filtering

Removes duplicates, test configs, and junk servers. Intelligent deduplication.

🧪

Continuous Testing

TCP ping, DNS resolution, HTTPS handshake. Only verified configs published.

📊

Real-time Stats

Live metrics: server count, uptime, speed, regional distribution.

🤖

CI/CD Automation

GitHub Actions: update every 2 hours. Automatic deployment and monitoring.

🔐

Open Source

Full transparency: source code on GitHub, no hidden functionality, MIT licensed.
