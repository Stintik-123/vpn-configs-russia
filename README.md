## 🎯 Что это?

**VPN-Configs-Russia** — это не VPN-сервис и не провайдер.

Это **инфраструктурный проект** по сбору, фильтрации и анализу VPN-конфигураций:

✅ Автоматически собирает конфиги из проверенных источников  
✅ Удаляет дубли и мусорные серверы  
✅ Тестирует доступность каждой конфигурации  
✅ Публикует только качественные конфиги  
✅ Обновляет список каждые 2 часа  

**Главная идея:** пользователь не должен вручную искать рабочий конфиг среди сотен мусорных.

## 🚀 Как использовать

### Способ 1: Через веб-сайт (30 сек)

```
1. Откройте https://Stintik-123.github.io/vpn-configs-russia/
```

## 🔍 Логика проверки серверов

### 1. Сбор конфигов
- Собираем из проверенных источников
- Поддерживаем: base64, plain-text, JSON
- Таймаут: 10 сек на источник

### 2. Нормализация и очистка
```python
# Удаляем:
- Дубликаты (по хешу ключевых параметров)
- Тестовые конфиги (по паттернам: test, expire, insecure)
- Невалидный синтаксис
- Старые протоколы

# Нормализуем:
- Сортировка параметров в URL
- Унификация формата
- Проверка целостности
```

### 3. Проверка доступности
```python
# Для каждого конфига:
TCP Ping → DNS резолв → HTTPS Handshake → Валидация
   ↓           ↓              ↓                  ↓
  1s           2s            3s            Статус: OK/FAIL
```

### 4. Фильтрация по качеству
- Только конфиги с успешной проверкой
- Минимум 3 из 5 проверок = OK
- Пороговое значение скорости: >100 Kbps
- Пороговое значение пинга: <300ms

### 5. Дедубликация
Ключи для сравнения:
```
scheme + hostname + port + protocol + security + sni + fp
```

## ❓ FAQ

**Q: Может ли это заменить VPN-провайдера?**  
A: Нет. Это инфраструктура для публикации конфигов. Сами серверы принадлежат различным провайдерам.

**Q: Безопасно ли использовать конфиги?**  
A: Конфиги собраны из открытых источников. Используйте на свой риск. Не рекомендуется для банковских приложений.

**Q: Как часто обновляются конфиги?**  
A: Каждые 2 часа автоматически через GitHub Actions.

**Q: Можно ли добавить свой источник?**  
A: Да! Отредактируйте `config/sources.json` и создайте PR.

**Q: Почему белые списки?**  
A: Белые списки используются мобильными операторами РФ для блокировки через РКН. Это техническая необходимость.

**Q: Какой тип подписки использовать?**  
A: Начните с чёрного списка. Если не работает → попробуйте белый. Если не работает SNI → попробуйте CIDR.
