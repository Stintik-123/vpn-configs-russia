📚 Гайды
▶ Как подключиться на Windows / Mac
1. Скачай Hiddify
2. Скопируй ссылку выше
3. В Hiddify: Новый профиль → Импорт из URL → вставить → Добавить
4. Нажми «Подключиться» и выбери сервер
▶ Как подключиться на Android / iOS
1. Установи Hiddify из магазина приложений
2. Скопируй ссылку
3. Открой Hiddify → нажми «+» → Импорт из URL → вставь → Добавить
4. Подключись
